# Beta feedback form — field list

Create a Google Form or Typeform with these fields. Keep it short — aim for **5 minutes** after the first training.

---

## Required

1. **Name or tester ID** (short text) — so you can match replies to Sentry/crash reports
2. **Device** (dropdown): iPhone / Android + model if they know it
3. **Who did you test for?** (single choice)
   - Myself (adult)
   - My child
   - Both
4. **Did you complete signup without help?** (Yes / No — if No, what blocked you?)
5. **Did you complete at least one training exercise?** (Yes / No)
6. **Could you follow the exercises from the instructions/images?** (1–5 scale)
7. **What was most confusing or frustrating?** (long text)
8. **What felt good or helpful?** (long text)
9. **Would you use this app again this week?** (Yes / Maybe / No — why?)

---

## Optional (Wave 2+)

10. Did you try the **child reflex profile questionnaire**? (Yes / No / N/A)
11. If yes: Was it **too long**, **unclear**, or **about right**?
12. Did you train **offline** or with **bad connectivity**? Any issues?
13. **Reminders**: did you enable them? Useful or annoying?

---

## Internal-only (don’t ask testers)

Track separately in your session log:

- Build number from `pubspec.yaml`
- TestFlight/Firebase install date
- Sentry issue URLs
- Follow-up call scheduled? (Y/N)
