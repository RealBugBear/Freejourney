Hi [Name],

1. Open this link on your **iPhone/Android**: [LINK]
2. Install and open the app.

**First session (~20–30 min):**

2. **Tap the confirmation link on the same device** (required).

6. Complete **at least one exercise** (images only for now — videos coming later).
